<h2>My Formatting Choices</h2>

<p>
For this project, I took my original paper, “Understanding an Effective Campaign:
Minecraft X McDonald's,” and reformatted it as an HTML document. My main goal was
to keep the ideas and rhetorical analysis from my original paper while making the
information easier to read and navigate on a webpage. I organized the paper into
several sections using <strong>HTML headings</strong> so readers can quickly identify
the main topics. The sections include the target audience, rhetorical appeals,
visual design, typography, color, and the overall effectiveness of the campaign.

<p>
I used CSS to create a simple layout with a white content area against a light
gray background. I also used a maroon header with white text for the title. This

the rest of the page. I chose maroon because it provides strong contrast with
white text while still matching the red branding associated with McDonald's.
</p>

about the campaign. <em>Italic text has a yellow background</em>, which makes
rhetorical terms such as <em>logos, pathos, and kairos</em> easy to identify.
